# robotframework-xyz

`robotframework-xyz` aims at providing templates for modrern RobotFramework libraries.

## Features

- [Devcontainer](https://containers.dev/)
- [VSCode](https://github.com/microsoft/vscode)
  - [d-biehl.robotcode](https://marketplace.visualstudio.com/items?itemName=d-biehl.robotcode)
  - [tamasfe.even-better-toml](https://marketplace.visualstudio.com/items?itemName=tamasfe.even-better-toml)
- Python Tooling
  - [uv](https://github.com/astral-sh/uv)
- Tests 
  - [RootFramework acceptance tests](https://github.com/fkromer/robotframework-xyz/tree/master/atests)
