# Security Policy

## Supported Versions

The latest version of this project is supported.
Please hard-pin the version of this project in your Robot Framework projects and update it as soon as possible.

## Reporting a Vulnerability

If you have discovered a security vulnerability in this project, please follow these steps:

1. **Do not disclose it publicly.**  
   Please avoid sharing the vulnerability details in any public forum (e.g., GitHub issues, public discussions) before it is resolved.

2. **Contact Us.**  
   Report the vulnerability by sending an email to [security@example.com](mailto:security@example.com). Include the following information:
   - A detailed description of the vulnerability.
   - Steps to reproduce the vulnerability, if applicable.
   - Any potential impact or severity you have assessed.

3. **Response Timeline.**  
   We will respond to your report within 72 hours. Our team will investigate the issue and provide a timeline for resolving it.

4. **Acknowledgment.**  
   If you wish, we will publicly acknowledge your contribution once the issue is resolved and if it is safe to disclose.
